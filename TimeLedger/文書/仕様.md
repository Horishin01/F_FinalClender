# 仕様

## 開発用データベース

- Development環境ではSQLiteを使用する。
- DBファイルはTimeLedger直下の `timeledger.db`。SQLiteの `timeledger.db-wal` と `timeledger.db-shm` も同じ場所に保存する。
- 開発の起動にDocker、PostgreSQL、接続資格情報は不要。
- 開発用Docker PostgreSQLのCompose、env、物理データ、移行スクリプトは保持しない。
- Production環境は引き続きPostgreSQLを使用し、`ConnectionStrings:DefaultConnection` を必須とする。
